Quy ước: Hoàn thành = code đã merge vào nhánh dev và FE gọi API thật. Đang làm = một phía xong, hoặc code nằm ở nhánh chưa merge, hoặc FE còn chạy mock. Chưa làm = không tìm thấy code. Điểm % chỉ đếm số hạng mục, không phải khối lượng.

Điểm lệch giữa báo cáo và source code

  • Revoke / restore distribution và gỡ tài liệu / người nhận: Báo cáo tuần ghi Implemented / Pending testing, nhưng không có endpoint nào trên bất kỳ nhánh nào của hogo-v3-backend. Cần push code.
  • Admin – documents / package của user: Đã code trên nhánh feature/admin-manage-users nhưng chưa merge vào dev.
  • Address book (FE): FE vẫn gọi API cũ /api/recipient thay vì /v1/contacts đã làm xong ở BE.
  • FE gọi endpoint BE chưa có: /v1/history, /v1/me/billing (GET), /access-report.csv, /admin/users/{id}/credits|history, /admin/payments/{id}/refund, /admin/messages, /v1/admin/me — hiện chỉ chạy được khi bật MSW mock.
  • WebhookWorker SecureDocs: Endpoint nhận webhook đã có nhưng 6 case xử lý event đều là // TODO → dashboard / trạng thái mở tài liệu chưa có dữ liệu.
  • Nhánh FE features/package: 3 commit (mock data cho send wizard) chưa merge vào dev.
